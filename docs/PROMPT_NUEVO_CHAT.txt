El proyecto
- Carpeta: ~/Documentos/control-clientes
- Repositorio privado: github.com/kirito203278/control-clientes
- Backend: Python + FastAPI + SQLAlchemy + PostgreSQL
- Frontend: React + TypeScript + Vite, compilado y servido por el backend
- 186 pruebas automatizadas, todas en verde
- Levantarlo para probar: docker compose -f docker-compose.demo.yml up --build
  (abre http://localhost:8000, usuario admin.demo, contraseña 10000001)
- Correr las pruebas: cd backend && python -m pytest -q
  (necesitan un PostgreSQL real; cada corrida crea y borra su propia base)
